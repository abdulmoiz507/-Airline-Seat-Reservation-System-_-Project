# ✈️ Airline Seat Reservation System

A console-based C++ application for managing airline seat reservations across three passenger classes on a single aircraft.

---

## 📋 Description

The Airline Seat Reservation System simulates a real-world flight booking interface. It manages an **84-seat aircraft** (12 rows × 7 seats) divided into three classes:

| Class          | Rows   | Seats | Fare (PKR) |
|----------------|--------|-------|------------|
| First Class    | 1 – 2  | 14    | Rs. 18,000 |
| Business Class | 3 – 4  | 14    | Rs. 14,000 |
| Economy Class  | 5 – 12 | 56    | Rs. 10,000 |


## 🛠️ Technologies Used

| Technology     | Details                                      |
|----------------|----------------------------------------------|
| **Language**   | C++ (Standard C++11 or later)                |
| **I/O**        | `iostream` — console-based input/output      |
| **Data Structure** | 2D integer array (`int[12][7]`) as the seat map |
| **Paradigm**   | Procedural programming with modular functions |
| **Compiler**   | Any standard C++ compiler (g++, MSVC, Clang) |
